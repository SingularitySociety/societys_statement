# README に Mulmo 系プロダクトへのリンクを足す

## やること

README の「公式メディア・SNS」の下に「Mulmo 系プロダクト」の表を置き、各プロダクトのサイト・ドキュメント・GitHub へリンクする。

## 載せる範囲

receptron の公開リポジトリのうち、単体で使うプロダクト本体だけ。プラグインや部品のリポジトリは載せない。

- MulmoCast（公式サイト / CLI / ドキュメント / 日本語 FAQ / デスクトップアプリ）
- MulmoClaude（ドキュメントサイト / セットアップ / GitHub）
- MulmoTerminal（公式サイト / ドキュメントサイト / 日本語ガイド / GitHub）
- MulmoChat（GitHub。研究用プロトタイプでサイトは無い）

リンクは全部開けることを確認してから載せる。
