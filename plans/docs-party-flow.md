# 宴会（懇親会）の進め方を文書にする

## やること

`party.md` を新しく作り、宴会の流れを時間順に書く。受け取ったメモは次の 5 点。

- イベント終了から現地でのネットワーキングと移動時間を考慮する
- 事前に出欠を取る。出欠締め切り厳守
- お店のキャンセル規定、キャンセル締め切りを把握する
- キャンセル締め切り前日までに PayPay / 振込で会費を集める。入金ない人はキャンセル
- キャンセル締め切り後のキャンセルは返金なし

守りたい 3 点は冒頭の「大事にすること」に置く。当日のお金のやり取りを減らす、キャンセル時に幹事に負担をかけない、参加者は出欠と事前精算をあいまいにしない。

## 構成

- 冒頭に「大事にすること」3 点
- 「時間の流れ」で、お店のキャンセル締め切りを起点に逆算する順序を縦の図で示す（mermaid は未設定なのでテキスト図）
- 段階ごとの節を時間順に並べ、幹事と参加者のどちらがすることかを書く

## 置き場所

- トップレベルの `party.md`。`meeting.md` の子にはしない（会議ではないため）
- README の「コミュニケーション・会議」にリンクを足す
