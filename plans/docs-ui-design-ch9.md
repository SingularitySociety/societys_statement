# UI設計の基礎に第9章「操作させない・失わせない」を足す（Issue #137）

## ゴール

連載（8章＋付録2）に、今どきの入力の作法を第9章としてまとめる。利用者に余計な操作をさせない、入力したものを失わせない、ログインと登録の画面の悪い癖を避ける、の三つ。図つき。あわせて、保存ボタン前提で古く読める二箇所（第1章の表、第7章の指示文の例）を直す。

## 方針

- 構成は既存章と同じ。ひとことで → なぜ → 節ごとに「説明、図、避けたい例と改善例の表」 → やってみる → 出典
- 図は SVG で `images/ui_design/09-*.svg`。左が避けたい例、右が改善例
- 出典は開けることを確認したものだけ。「最新版」を名乗るものは版を明記する（WCAG 2.2、NIST SP 800-63B 第4版）
- 「パスワードを隠す」は Apple の指針が勧める作法なので否定しない。隠したままにせず、表示の切り替えを付ける、と書く

## 章の中身

```
development/ui_design/09-no-extra-work.md   操作させない・失わせない
  1. 聞かない           システムが分かることは入力させない（Apple HIG データの入力、ソシオメディア 29・39・45、WCAG 2.2 3.3.7）
  2. 寛容に受け付ける   形式・文字種を限定しない（デジタル庁 インプットテキスト、NN/g スリップ、ソシオメディア 18）
  3. 失わせない         自動保存・下書き・取り消し（ソシオメディア 38、NN/g ミス、Apple HIG 取り消し/やり直し）
  4. ログインと登録の悪い癖   パスワードを隠したまま、メールアドレスを二回、貼り付け禁止、複雑さのルールと定期変更
                        （NIST SP 800-63B 第4版、WCAG 2.2 3.3.8、web.dev、GOV.UK、NN/g）
images/ui_design/09-ask-less.svg, 09-forgiving.svg, 09-autosave.svg, 09-login.svg
```

## 出典（確認済み）

- Apple「Human Interface Guidelines」データの入力 — システムから取れる情報は聞かない、選択肢を出す、貼り付けを許す
- デジタル庁デザインシステム インプットテキスト: 使い方 — 入力値の文字種を限定しない
- WAIC「WCAG 2.2 日本語訳」 — 3.3.7 冗長な入力項目、3.3.8 アクセシブルな認証（最低限）
- NIST SP 800-63B（第4版） — 貼り付けとパスワードマネージャーを許す、表示の選択肢、文字種の組み合わせを強制しない、定期変更を求めない
- web.dev「ログイン フォームのベスト プラクティス」（日本語） — 入力を重複させない、表示の切り替え
- GOV.UK Design System「Passwords」 — let users paste their password
- NN/g — Preventing User Errors: Avoiding Unconscious Slips（寛容な形式、提案、初期値）／Avoiding Conscious Mistakes（取り消し）／Stop Password Masking／Password Creation／Website Forms Usability
- ソシオメディア HIG — 29 ユーザーがとれる操作がひとつしかないなら自動化する、39 整合性を損なうような操作をユーザーに求めない、45 値を入力させるのではなく結果を選ばせる、18 複雑性保存の法則、38 ユーザーが入力したものはユーザーのもの
