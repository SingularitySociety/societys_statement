# 付録A　用語ミニ辞典

> 連載の入口 → [UI設計の基礎](README.md)

連載に出てくる言葉を、出てくる順ではなく五十音順に並べました。

| 用語 | 意味 | 出てくる章 |
| --- | --- | --- |
| アクセシビリティ | 目・手・環境の条件が違っても使えること | [第6章](06-accessibility.md) |
| アフォーダンス | 物がどう扱えるかという性質そのもの。取っ手は「引ける」。ノーマンが広めた言葉で、後に「見せる手がかり」はシグニファイアと呼び分けた | [第2章](02-self-evident.md) |
| 一貫性 | 同じ意味のものを同じ見た目・場所・言葉にすること | [第1章](01-consistency.md) |
| ゲシュタルト（視覚ゲシュタルト） | 近いもの・似たものをまとまりとして見る、人の目の性質 | [第5章](05-layout.md) |
| コントラスト比 | 文字と背景の明るさの差。WCAG は通常の文字で4.5対1以上 | [第6章](06-accessibility.md) |
| 制約（コンストレイント） | できないことを、できないように見せる・させないこと | [第4章](04-feedback-errors.md) |
| 代替テキスト | 画像やアイコンの代わりに読み上げられる言葉 | [第2章](02-self-evident.md)、[第6章](06-accessibility.md) |
| チェックボックス | 複数の項目から好きな数だけ選ぶ部品。保存と一緒に効く | [第3章](03-labels-switches.md) |
| デザインシステム | 色・文字・部品とその使い方をまとめた公開の設計指針。デジタル庁、Apple、Google が公開している | [第1章](01-consistency.md) |
| トグル（スイッチ） | 切り替えた瞬間に効く二択の部品 | [第3章](03-labels-switches.md) |
| ヒックの法則 | 選択肢が増えるほど、選ぶのに時間がかかる | [第5章](05-layout.md) |
| ヒューリスティック | 経験から導いた判断の目安。NN/g の「10原則」はこの意味 | [第1章](01-consistency.md) |
| フィードバック | 操作の結果がすぐ返ってくること | [第4章](04-feedback-errors.md) |
| フィッツの法則 | 目標が大きく近いほど、速く正確に押せる | [第5章](05-layout.md) |
| フォーカス | キーボード操作で、いま選ばれている部品。見えていないと迷子になる | [第6章](06-accessibility.md) |
| プレースホルダー | 入力欄の中に薄く出る入力例。ラベルの代わりにしない | [第3章](03-labels-switches.md) |
| メンタルモデル | 利用者が頭の中に持っている「こう動くはず」という理解 | [第1章](01-consistency.md) |
| ラジオボタン | 複数の選択肢から一つだけ選ぶ部品 | [第3章](03-labels-switches.md) |
| シグニファイア | 「ここは押せる」「ここに書ける」と見せる手がかり | [第2章](02-self-evident.md) |
| スクリーンリーダー | 画面を読み上げる道具。目が見えない人、見えにくい人が使う | [第6章](06-accessibility.md) |
| UI | ユーザーインターフェース。人が触れる画面と操作 | 全章 |
| UX | ユーザー体験。画面だけでなく、使う前後を含めた体験全体 | 全章 |
| WCAG | ウェブコンテンツ・アクセシビリティ・ガイドライン。W3C が定める国際基準 | [第6章](06-accessibility.md) |
