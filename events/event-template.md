# イベント準備テンプレート

時系列順に並べている。上から順に進める。

## 3ヶ月前: 企画・会場

### 決めること

- 日程
- イベントの時間
- 内容案（ここで確定させる）
- 体制
  - スタッフ
  - 司会者
  - 登壇者募集責任者
  - 集客責任者
  - 録画・配信担当者
  - SNS 担当者
- 録画・配信（告知に載せるのでここで決める）
  - 録画の有無
  - 録画の外部共有
  - YouTube 配信の有無
  - Zoom（Meet）配信の有無

### 会場選びと確認項目

- 会場
  - 利用可能な時間
  - 人数上限
  - 部屋数上限
  - 控室の有無
  - Wifi、マイク等の設備
  - 飲食の可否
  - 入館方法
  - 懇親会

## 2ヶ月前: 告知

- 集客方法を決めて告知する
- 登壇者を募集する

### 懇親会

- 会費と集金方法を決める（当日現金、事前決済など）
- キャンセル締切を決め、告知に載せる（店の人数確定日より前にする）
- 出欠受付を始める（connpass の申込枠を分ける、またはアンケートで聞く）

### connpass の注意点

- イベントを作成してもグループのイベント一覧には出ない。管理人に追加してもらい、URL をシェアする
- 編集画面の上部は参加者・発表者への連絡を書く欄。イベント説明は下部に書く
- 参加者個別のメールアドレスは取得できず、個別に連絡もできない。必要な情報はアンケートに項目を追加して集める（作成時に設定しておく）

### connpass 申込時アンケートの例

必要なものだけ選ぶ。聞きすぎると申込が減る。

- 氏名（フルネーム）: 会場の入館登録で必要な場合
- 所属（会社・学校など、任意）
- 職種（エンジニア、デザイナー、PM、学生、その他）
- 経験・レベル（例: 初めて触る / 業務で使っている）
- このイベントを知ったきっかけ（connpass、X、知人、その他）
- 参加の目的・期待すること（自由記述）
- 登壇者・テーマへの質問（自由記述、任意）
- 懇親会への参加有無
- 食事制限・アレルギー: 食事やデリバリーがある場合
- 写真・録画への写り込みの可否
- 連絡用メールアドレス（任意）: 個別連絡が必要な場合

### SNS 運用（ここから開始）

- ハッシュタグを決め、告知文と connpass に載せる
- 告知投稿（connpass の URL を添える）
- 登壇者が決まり次第、登壇者紹介を投稿
- 配信ありなら配信情報（日時、配信先）を投稿

## 1ヶ月前: コンテンツ確定

- コンテンツ・登壇者を確定する
- デリバリーの有無

## 2週間前

- タイムテーブルの最終決定
- 当日のスタッフの役割分担（受付、司会、録画・配信、SNS、会場案内）
- 登壇資料の提出締切を登壇者に連絡
- 配信する場合は配信 URL を発行し、connpass・SNS で共有
- 登壇者に配信・録画の有無を伝え、資料の公開可否を確認
- デリバリーの手配
- 懇親会の会場・店を予約（その時点の出欠数で仮押さえ）

## 1週間前

- 登壇者の入り時間の最終確認
- スタッフの当日の入り時間の確認
- 機材等の漏れがないかチェック（マイク、プロジェクター、変換アダプタ、延長コード、録画・配信機材）
- 参加人数を確認し、会場・デリバリーに人数を伝える
- 懇親会のキャンセル締切で出欠を締め、人数を確定して店に伝える
- 懇親会参加者に会費と集金方法を改めて連絡
- connpass の連絡欄で参加者にリマインド（タイムテーブル、持ち物、配信 URL、ハッシュタグ）
- SNS でリマインド投稿（タイムテーブル、配信 URL）
- 当日の SNS の運用を決め、登壇者・スタッフに伝える（下記「当日の SNS」）
- 参加者アンケートを作成（Google フォームなど。URL を締めのスライドに載せる）

## 前日

- 入館方法の確認
- 現地までの案内の確認（connpass に掲載し、参加者・登壇者に伝わっているか）
- 登壇資料が揃っているか確認
- 機材の充電、録画・配信のテスト
- 配信 URL が connpass・SNS に正しく載っているか確認

## 当日

### タイムテーブル

1. スタッフ入場、会場設営、機材・配信の動作確認
2. 登壇者入場、接続確認
3. 一般参加者入場、受付
4. オープニング（ハッシュタグ、写真撮影の可否、SNS での質問受付を案内）
5. コンテンツ
6. ランチ
7. コンテンツ
8. 締め
   - ブログ・SNS での感想シェアのお願い（ハッシュタグ付き）
   - 登壇者に資料共有のお願い
   - 参加者にアンケートのお願い（URL・QR コードを表示）
9. 懇親会（受付で出欠確認、会費を集金）
10. 撤収、忘れ物確認

### 当日の SNS

- ハッシュタグを会場（スライド、掲示）で伝える
- 会場の写真をリアルタイムで投稿する（写り込みに配慮）
- 配信中であることと配信 URL を投稿する
- 質疑を SNS（ハッシュタグ付き）で受け付け、司会が拾う

## 後日

- 参加者・登壇者へのお礼
- 懇親会の会計を締める（未払い・ドタキャンの確認）
- 登壇者に資料共有を改めてお願いし、集まったら connpass の資料欄に登録
- 参加者にアンケートを改めてお願い（connpass の連絡欄）、集計して振り返りに使う
- ブログ・SNS の感想を集めて紹介・共有
- 開催報告を SNS に投稿（写真、登壇資料のリンク）
- 録画の公開（外部共有する場合）と SNS での告知
- 振り返り（次回への改善点をこのテンプレートに反映）
