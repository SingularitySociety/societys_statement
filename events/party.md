# 宴会（懇親会）の進め方

イベントのあとの宴会を、幹事に負担をかけず、お金のやり取りでもめずに開くための流れです。

## 大事にすること

- **当日のお金のやり取りを、できる限りなくす。** 会費は事前に集め、当日は集金しません。
- **キャンセルの負担を幹事に負わせない。** お店のキャンセル料が発生する前に人数を確定し、それ以降のキャンセルは返金しません。
- **参加者は、出欠と事前精算をあいまいにしない。** 締め切りまでに出欠を答え、締め切りまでに会費を入金します。入金がなければ欠席として扱います。

## 時間の流れ

お店のキャンセル締め切りが起点です。そこから逆算して、入金締め切りと出欠締め切りを決めます。

```
お店を決める
  │  キャンセル規定とキャンセル締め切りを把握する
  ▼
出欠を募集する
  │  日時・場所・会費・各締め切りをまとめて告知する
  ▼
出欠締め切り（厳守）
  │
  ▼
会費の入金締め切り ＝ お店のキャンセル締め切りの前日
  │  入金のない人はキャンセル扱い
  ▼
お店のキャンセル締め切り
  │  幹事が確定人数をお店に伝える
  │  これ以降のキャンセルは返金なし
  ▼
当日
     会費は集めない。幹事がまとめて支払う
```

たとえばお店のキャンセル締め切りが「3日前」なら、入金締め切りは 4日前、出欠締め切りはそれより前に置きます。

## 1. お店を決める（幹事）

- 開始時刻は、イベントの終了時刻に、現地でのネットワーキングの時間と、お店までの移動時間を足して決めます。
- お店のキャンセル規定と、キャンセル締め切りがいつかを確認します。この日付が、あとの締め切りすべての起点になります。
- 会費を決めます。

## 2. 出欠を募集する

- **幹事** は、日時・場所・会費・出欠締め切り・入金締め切り・「キャンセル締め切り後は返金なし」を、募集のときにまとめて伝えます。あとから「知らなかった」が出ないようにするためです。
- **参加者** は、出欠締め切りまでに出欠を答えます。

## 3. 出欠締め切り（厳守）

- 締め切りを過ぎてからの出席の追加や変更は受け付けません。
- 幹事は、ここで出席予定の人数を把握します。

## 4. 会費を集める（入金締め切り）

- 入金締め切りは、お店のキャンセル締め切りの前日です。
- **参加者** は、入金締め切りまでに PayPay か振込で会費を払います。
- **幹事** は、入金のない人をキャンセル扱いにします。返事だけで入金のない人は、出席者に数えません。

## 5. お店のキャンセル締め切り

- 幹事は、入金のあった人数をお店に確定人数として伝えます。
- これ以降のキャンセルは返金しません。お店にキャンセル料が発生するためで、その分を幹事がかぶらないようにする決まりです。

## 6. 当日

- 会費はすでに集まっているので、当日の集金はありません。
- 幹事は、集めた会費でまとめて支払います。
