# カルチャーガイドの冒頭に「まず大切にしてほしいこと」を置く

## やること

`action-thinking-culture-guide.md` の冒頭に、受け取った 8 項目（AIじゃない理由 / コーチャブル / 本気 / ドッグフーディング / 完璧を求めない / 意見を聞くとき / 〇〇の機能があったら使う、という人は無視 / 議論のための議論はしない）を見出しつきで置く。本文は受け取ったまま。直すのは太字の区切り・「ドッグフーディング」・百分率の表記だけ。

## 後ろの重複の扱い

消す前に、消す側にしか無い内容を冒頭へ移す。

| 後ろの箇所 | 扱い |
| --- | --- |
| 行動原則の「コーチャブルでない人には…」 | 消す。「探すべきで、変えようとしても無理」は冒頭のコーチャブルへ |
| 行動指針の「完璧よりも動くもの」 | 節ごと消す。サグラダ・ファミリアと「協力者やアイデアがでてくるかも」は冒頭の「完璧を求めない」へ |
| 「議論よりプロトタイプ」の「議論のための議論は無駄です」 | その一文だけ言い換える。プロトタイプの節は残す |
