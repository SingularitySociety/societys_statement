# UI設計の基礎に第8章「迷わせない」を足す（Issue #135）

## ゴール

PR #134 で入れた連載（ハブ＋7章＋付録2）に、未収録だった原則を第8章としてまとめる。図を付けて、読まなくても見れば分かる形にする。図は第8章だけでなく、第1章から第7章にも入れる（依頼「図に関しては、全部の章に入れてね」）。

## 方針

- 構成は既存章と同じ。ひとことで → なぜ → 原則ごとに「説明、図、避けたい例と改善例の表」 → やってみる → 出典
- 図は SVG で `images/ui_design/` に置く（リポジトリの既存の置き場 `images/<ページ名>/` に合わせる）。左が避けたい例、右が改善例。どの図も `title`・`desc`・代替テキストを付ける
- 出典は開けることを確認したものだけ。本文で名前を挙げる記事にはリンクを付ける
- 英語の原則名は日本語にし、原文の名前を添える

## 章の中身

```
development/ui_design/08-wayfinding.md   迷わせない
  1. 現在地と進み具合を見せる   手順の何番目か（ステップナビゲーション）、パンくず、処理中の表示、空の画面
  2. 利用者の頭の中の絵に合わせる   概念モデル、対応づけ（マッピング）、モードを作らない
  3. 最初は少なく、必要なら深く   段階的開示（ディスクロージャー）、良い初期値
  4. 初心者にも熟練者にも   近道（ショートカット、ウィザードとの使い分け）、助けは必要な場所に短く

```
